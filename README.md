# Thinking Costs Calibration in Diffusion Decision Models: code and data

Code, frozen data splits, per-item outputs, and analysis scripts for the paper
*Thinking Costs Calibration in Diffusion Decision Models* (Shaik Aman, Jeyakumar Chinnathambi).
The paper source is in `paper/`.

## Contents

- `dd/`: harness (data and the synthetic jagged set, canvases C0/C1/C2, denoising loops, slot readout, metrics, escalation, report).
- `configs/`: one YAML per run (smoke, dev, test, end-token ablation, Qwen baselines, Dream, T=32).
- `scripts/`: run scripts per phase and the exploratory CPU analyses.
- `tests/`: unit tests that do not load model weights.
- `results/splits.json`, `results/items.jsonl`: the frozen dev/test items (option order fixed by a SHA-256 hash of the item id).
- `results/raw*/`: one JSON line per item per cell, for every run reported in the paper.
- `results/*.json`, `results/summary.csv`, `results/*.md`: computed results; `results/HYPOTHESES.md` (pre-registered hypotheses)
  and `results/CLAIMS.md` (claim-to-source map). The internal run log (`results/LOG.md`) is not included;
  the runners create a fresh one when rerun.
- `paper/`: LaTeX source, generated tables and figures, and `check_numbers.py`.
- `PLAN.md`: the pre-registered plan.

## Reproduce the analyses from the included outputs (CPU only)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m dd.report                  # summary.csv, hypothesis_tests.json, escalation_test.json, REPORT.md
python scripts/dev_v12.py            # dev escalation report
python scripts/analysis_v13.py       # v1.3 exploratory A1-A5
python scripts/analysis_v13_bc.py    # v1.3 exploratory B (T=32) and C (Dream)
python scripts/analysis_v14.py       # v1.4 exploratory B1-B3
python scripts/paper_numbers.py      # derived numbers used in the prose
python paper/make_tables.py && python paper/make_figures.py
python paper/check_numbers.py        # every number in the prose against results files
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Rerun the model sweeps (GPU)

The reported runs used one NVIDIA L4 (24 GB), bf16, batch size 1, greedy decoding, Python 3.12, and
`transformers==4.46.3` (pinned in `requirements.txt`). Model revisions are pinned in `configs/`.
Every runner is resumable: it skips items already present in `results/raw*/`, so delete the
corresponding files first to regenerate them.

```bash
bash bootstrap.sh                       # environment, model download, unit tests, load check
python -m dd.run --config configs/resmoke.yaml   # protocol v1.1 template check
bash scripts/run_phase23.sh             # anytime gate, LLaDA dev sweep and temperatures, Qwen3-8B dev
bash scripts/run_phase4.sh              # LLaDA 13-cell test grid, Qwen3-8B C0 test, end-token ablation
bash scripts/run_v13.sh                 # exploratory: Dream-v0-Instruct-7B and LLaDA T=32
bash scripts/run_v14.sh                 # exploratory: Qwen2.5-7B Instruct and base C0 baselines
```

`bootstrap.sh` assumes an AWS Deep Learning AMI (PyTorch, Ubuntu) and links its CUDA PyTorch into the
venv; on another machine, install a CUDA build of PyTorch and then `pip install -r requirements.txt`.
The Qwen3-8B baseline uses a separate venv with `transformers==4.56.2` (see `scripts/run_phase23.sh`).
`scripts/run_v13.sh` runs Dream in a second checkout at `~/dlm-dream`.

## Data

`results/items.jsonl` (and the item text inside `results/raw*/`) contains reformatted items from three
public datasets, rendered as lettered multiple choice with shuffled options. Each keeps its original license:

- BoolQ (Clark et al., 2019), validation split via `google/boolq`: CC BY-SA 3.0,
  <https://github.com/google-research-datasets/boolean-questions>
  (license: <https://creativecommons.org/licenses/by-sa/3.0/>).
- StrategyQA (Geva et al., 2021), train split via `ChilleD/StrategyQA`: MIT,
  <https://github.com/eladsegal/strategyqa> (license: <https://github.com/eladsegal/strategyqa/blob/main/LICENSE>).
- ARC-Challenge (Clark et al., 2018), test split via `allenai/ai2_arc`: CC BY-SA 4.0,
  <https://huggingface.co/datasets/allenai/ai2_arc> (license: <https://creativecommons.org/licenses/by-sa/4.0/>).

The reformatted BoolQ and ARC items are shared under the same CC BY-SA licenses. The jagged items are
synthetic and generated by `dd/data.py`.
