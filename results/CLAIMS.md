# Claims register

One row per claim the paper might make. Every number comes from the file named in **Evidence**. **Status** separates pre-registered tests (PLAN.md and HYPOTHESES.md, frozen before test) from exploratory analyses (v1.3/v1.4, decided after the test results were seen). ⚠ **one model** marks a claim shown for a single diffusion model. Statistics: paired bootstrap, 1000 resamples, 95% CI; McNemar exact.

**Framing decision (Aman, 2 Oct 2026):** the paper makes **no claim that diffusion is inherently better calibrated than autoregressive models**. Rows 10a and 10b are kept as context only.

Models: LLaDA = LLaDA-8B-Instruct (main); Dream = Dream-v0-Instruct-7B (exploratory, original test items only, S=32 only). Test = 1000 / 1000 / 1000 / 600 items (BoolQ / StrategyQA / ARC-C / jagged); "original" = the 400 / 400 / 400 / 240 subset.
